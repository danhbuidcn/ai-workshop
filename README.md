## Mở thế nào

- Mở [index.html](index.html) ở gốc: hiện danh sách buổi, bấm vào buổi để xem slide.
- Trên máy (Windows): tải repo (**Code → Download ZIP**), giải nén, bấm đúp `index.html`. Không cần cài gì, không cần mạng.
- Máy trung gian Gemini dùng chung cho mọi buổi: [proxy/HUONG-DAN.md](proxy/HUONG-DAN.md).
